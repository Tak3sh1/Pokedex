## 📋 Sobre o Projeto

Uma Pokédex completa e interativa que consome a [PokéAPI](https://pokeapi.co/) para exibir informações dos 151 Pokémon da primeira geração. O projeto demonstra habilidades em JavaScript assíncrono, consumo de APIs REST, manipulação de DOM e design de interface moderna.

### 🎯 Demonstrações de Habilidade

- ✅ JavaScript Assíncrono (Async/Await, Promises)
- ✅ Consumo de API REST (Fetch API)
- ✅ Manipulação de DOM (Criação dinâmica de elementos)
- ✅ UI/UX Design (Interface moderna e responsiva)
- ✅ Filtros e Busca (Em tempo real)
- ✅ Modais Interativos (Detalhes dos Pokémon)
- ✅ Gerenciamento de Estado (Filtros, busca, loading)

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🔍 Busca | Busca por nome ou número da Pokédex |
| 🎨 Filtros | 18 tipos diferentes de Pokémon |
| 📊 Estatísticas | HP, Ataque, Defesa, Velocidade e mais |
| 🖼️ Arte Oficial | Imagens de alta qualidade dos Pokémon |
| 📱 Responsivo | Adaptado para todos os dispositivos |
| ⚡ Loading | Feedback visual durante carregamento |
| 🎯 Modal Detalhado | Informações completas de cada Pokémon |
